# Writing Standards Registry

This directory contains evidence-governed, reusable scientific-writing rules.

Use together with:
- `references/living-writing-standards.md`
- `knowledge/templates/writing-standard-entry.md`

## Status legend

- **RAW** — recorded, not yet generalized.
- **SUPPORTED** — external evidence broadly supports the rule.
- **CONDITIONAL** — valid only under stated conditions.
- **DISPUTED** — important counterevidence or overgeneralization exists.
- **ADOPTED** — active guidance for this skill within its stated scope.
- **RETIRED** — retained for history but no longer active.

## Governance note

These entries are intentionally not treated as immutable law. A rule may be revised when:
- a target venue gives explicit contrary guidance;
- repeated high-quality counterexamples show that its scope is too broad;
- a new manuscript context exposes an edge case;
- the rule causes overcorrection.

Project-specific choices belong in a project profile / decision ledger, not here.
