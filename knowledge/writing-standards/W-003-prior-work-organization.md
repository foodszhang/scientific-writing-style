# W-003 — Organize prior work by methodological role rather than paper-by-paper narration

**Status:** CONDITIONAL  
**Category:** Introduction / Citation

## Original comment

Prior-work paragraphs written as sequential mini-summaries of individual papers were judged to read like a bibliography rather than an argument.

## Trigger example

> A proposed X. B proposed Y. C proposed Z.

## Underlying concern

The paragraph does not explain why the cited works matter to the present technical gap. The reader receives a list of papers rather than a methodological progression, contrast, or taxonomy.

## External verification

### Official guidance

No explicit IEEE/TMI rule identified that prohibits paper-by-paper narration.

### Recent-paper evidence

Formal sampling is pending. The working hypothesis is that mechanism-, assumption-, or limitation-based grouping is usually more informative when several papers serve the same rhetorical function.

## Assessment

**Judgment:** Context-dependent

**Reason:** Paper-by-paper chronology can be appropriate when historical sequence matters or when a small number of landmark works must be distinguished. It is usually weak when many papers are listed without an organizing relation.

## Current rule

When multiple papers serve the same rhetorical function, group them by methodological mechanism, assumption, data regime, or limitation. Use paper-by-paper narration only when chronology or individual distinctions are themselves important to the argument.

## Examples

### Avoid when this rule applies

> A proposed X. B developed Y. C introduced Z.

### Prefer

> Existing learned reconstruction methods mainly improve either measurement encoding or spatial decoding, while fewer works explicitly separate the approximation spaces used before and after discretization.
