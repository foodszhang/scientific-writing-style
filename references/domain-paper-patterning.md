# Domain-Paper Patterning

Use this process when the task is more than local wording repair.

The purpose is to make the manuscript read like work from its actual field without copying another paper's prose.

## 1. Select reference papers

Prefer 2–3 papers that are:
- in the same or closely related subfield;
- recent enough to reflect current field conventions;
- from the target venue or a comparable venue when possible;
- structurally relevant to the section being revised.

A useful set often contains:
- one paper with a method structure similar to the current work;
- one recent strong paper in the exact application domain;
- one paper with a particularly relevant Experiments or Discussion section.

Do not use a paper merely because it is famous if its rhetorical structure is not comparable.

## 2. Extract structure, not sentences

For each reference paper record:
- section/subsection order;
- role of each paragraph;
- opening move;
- transition logic;
- level of implementation detail;
- way results are tied to figures/tables;
- way Discussion relates results to prior work;
- canonical field terminology.

Do **not** build a phrase bank from copyrighted prose. Paraphrase the rhetorical skeleton.

## 3. Compare the current manuscript

For the target section ask:
- Does it perform the same essential scientific functions?
- Is an expected move missing?
- Is a paragraph carrying two incompatible jobs?
- Is implementation detail appearing where interpretation should be?
- Is terminology inconsistent with field usage?
- Is the manuscript making a stronger claim than comparable papers usually make from similar evidence?

## 4. Write from the function map

Draft only after the comparison.

Recommended order:
1. preserve the manuscript's scientific content;
2. adopt the field-appropriate rhetorical order;
3. use canonical field terminology;
4. keep only the level of detail needed for that section;
5. run claim-strength and terminology checks.

## 5. Source transparency

When a section is substantially patterned after published papers, distinguish:
- what is directly supported by the manuscript/data;
- what is a field convention inferred from the reference papers;
- what is the editor/agent's own structural recommendation.

Never invent experimental details to make the manuscript resemble the references.

## 6. Minimum patterning reports

### Introduction
Extract:
- how the field/problem is opened;
- how prior methods are grouped;
- how the gap is stated;
- how the study aim and contributions are introduced.

### Methods
Extract:
- whether task formulation precedes equations;
- where the overview figure is explained;
- how each module is motivated and interfaced;
- what implementation detail is deferred.

### Experiments
Extract:
- data-generation/acquisition order;
- comparator protocol;
- metrics/statistics placement;
- how reproducibility details are distributed.

### Results
Extract:
- whether the paragraph begins from a table/figure or scientific question;
- how much numerical detail is repeated from tables;
- how observation and interpretation are separated.

### Discussion
Extract:
- how the first paragraph positions the findings;
- how mechanisms are discussed;
- where prior work is cited;
- how limitations are framed;
- how the section differs from the Conclusion.
